## Agentmetry

[**Agentmetry**](https://github.com/blitzcrieg1/agentmetry) is a local-first security sensor for AI coding agents. It records tool activity reported by supported hooks and wrapped MCP servers, detects risky sequences, and keeps a verifiable audit trail you can forward to your SIEM.

[Website & demo](https://agentmetry.ai/) · [Install from PyPI](https://pypi.org/project/agentmetry/) · [Release notes](https://github.com/blitzcrieg1/agentmetry/releases)
